📋 What is this?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
A beautiful, easy-to-use tracker for Striver's A2Z DSA Sheet (402 problems).
Track your progress, add notes, schedule revisions, and analyze your stats!


🚀 How to Use (Super Easy!)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Open the file
   → Double-click "dsa-tracker-pro.html"
   → It will open in your default browser (Chrome, Firefox, Edge, Safari)
   → Make sure you have internet connection (needed to load problems)

STEP 2: Start tracking!
   → Check the box when you solve a problem ✓
   → Your progress saves automatically (no login needed!)


✨ Main Features
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📊 DASHBOARD
   • See your overall progress (circular chart)
   • Track your daily streak 🔥
   • View solved/remaining problems

🎛️ FILTERS (Left Sidebar)
   • Search problems by name
   • Filter by step/module
   • Filter by difficulty (Easy/Medium/Hard)
   • Filter by platform (LeetCode/GFG/TakeUForward)
   • Show only solved/unsolved/revision problems

📝 ADD NOTES
   • Click the 📝 icon on any problem
   • Add your own notes, hints, or approaches
   • Notes save automatically

⏰ REVISION QUEUE
   • Click the ⏱️ icon to schedule a problem for revision
   • Choose when to review (e.g., in 7 days)
   • Check revision queue from top menu

🎲 RANDOM PROBLEM
   • Click 🎲 in top menu
   • Get a random unsolved problem to practice
   • Perfect for daily challenges!

📊 STATISTICS
   • Click 📊 in top menu
   • See detailed breakdown by difficulty & platform
   • Track your progress over time

🌙 DARK MODE
   • Click 🌙 in top menu to toggle
   • Easy on the eyes for night coding sessions!

💾 BACKUP YOUR PROGRESS
   • Click 💾 icon to export your data
   • Save the JSON file as backup
   • Import it later to restore progress

❓ Common Questions
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: Do I need to install anything?
A: No! Just open the HTML file in any browser.

Q: Will my progress be saved?
A: Yes! It saves automatically in your browser's local storage.

Q: What if I close the browser?
A: Your progress is saved! Open the file again and everything will be there.

Q: Can I use this on my phone?
A: Yes! Send the file to your phone and open it in any mobile browser.

Q: I want to use this on multiple devices. How?
A: Export your progress (💾 button), then import it on other device.

Q: Does this need internet?
A: Yes, but only to:
   - Load the 402 problems (once when you open)
   - Click links to LeetCode/GFG websites
   Everything else works offline!

Q: I lost my progress! Help?
A: If you cleared browser data, progress is lost. Always export backups regularly!

Q: Can two people use the same file?
A: They can use copies of the file, but each browser saves its own progress separately.
   Send your friend a fresh copy so they can track independently.

🔧 Troubleshooting
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "Loading problems..." never finishes
   → Check your internet connection
   → Try refreshing the page (F5)
   → Try a different browser

❌ Progress not saving
   → Make sure you're not in incognito/private mode
   → Check if browser cookies are enabled
   → Try a different browser

❌ File won't open
   → Right-click file → Open With → Choose your browser
   → Make sure file extension is .html
